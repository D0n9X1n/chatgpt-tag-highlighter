General

Tag Rules (order matters)

startsWith — matches chats whose title begins with the tag. Best for prefixes like [TODO], [BUG].

includes — matches chats whose title contains the tag anywhere. Good for keywords like code, help.

Rules are checked top-to-bottom — the first match wins. Drag ≡ to reorder.
